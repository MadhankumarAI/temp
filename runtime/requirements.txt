# Perception runtime dependencies.
#
# Pinned to the versions this was built and tested against, not to ranges. A
# range means the next person's install is a different program from the one the
# numbers in the README describe, and "works on my machine" is exactly the
# failure a requirements file exists to prevent. Loosen deliberately, one line
# at a time, after re-running runtime/selftest.py.
#
# Python 3.11. numba does not support every newer release on day one and it is
# the hardest pin here to move.
#
# ---------------------------------------------------------------------------
# TORCH: INSTALL THIS FIRST, AND FROM THE CUDA INDEX
# ---------------------------------------------------------------------------
# `pip install torch==2.5.1` gets the DEFAULT wheel, which on many platforms is
# CPU-only. It imports, it runs, torch.cuda.is_available() returns False, and
# the stack silently falls back to the CPU: everything still works and the
# detector goes from 22 ms to about 190 ms. Nothing errors, which is why this
# warning is at the top.
#
#   pip install torch==2.5.1+cu121 --index-url https://download.pytorch.org/whl/cu121
#   pip install -r requirements.txt
#
# Then check it took, before trusting any timing:
#
#   python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
#   -> 2.5.1+cu121 True
#
# cu121 is CUDA 12.1. Match it to your driver; a mismatch fails at import with
# a clear message rather than silently, so this is the safe thing to change.
torch==2.5.1+cu121
